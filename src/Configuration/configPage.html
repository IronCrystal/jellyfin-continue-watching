General
Master switch. When off, the plugin does nothing and Jellyfin responds as normal.
Other clients keep Jellyfin's default behaviour. This applies to every option below.

Continue Watching list
Don't add a Next Up episode for a series that already has an episode in progress.
Sorts each Next Up episode by whichever is more recent: when you last watched the series, or when the episode was added to your library. When off, only the last-watched date is used.
Ignores series where you only opened an episode briefly. Jellyfin normally adds a series to Next Up as soon as any episode is opened.

Separate Next Up list
Returns an empty list for Jellyfin's Next Up request, since those episodes now appear in Continue Watching. Applies to every client, or only to Infuse if the option above is on. Clients that use this request to find the next episode to play may stop doing so.
