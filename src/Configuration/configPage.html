Master switch. When off, the plugin does nothing and Jellyfin responds as normal.
Other clients keep Jellyfin's default behaviour. This applies to every option below.

Continue Watching list
Don't add a Next Up episode for a series that already has an episode in progress.
Sorts each Next Up episode by whichever is more recent: when you last watched the series, or when the episode was added to your library. When off, only the last-watched date is used.
Ignores series where you only opened an episode briefly. Jellyfin normally adds a series to Next Up as soon as any episode is opened.

Next Up settings

Each user's own "Max days in Next Up" and "Enable rewatching in Next Up" (set in the web app under Settings > Home) are picked up the next time they open the home page in the web app, Jellyfin Desktop, or Jellyfin for Android. This needs the Next Up home section turned on; to avoid showing Next Up twice, use "Hide the separate Next Up list" below instead of removing the section. These defaults apply to users whose settings haven't been seen yet, for example users who only use Infuse.

Same default as the web app: 365.

Separate Next Up list
Returns an empty Next Up list, since those episodes now appear in Continue Watching. The next-episode lookup on a series page keeps working.

Cache
The list is rebuilt immediately when watch progress or the library changes. This is a safety net for anything that doesn't raise an event, such as changing which libraries a user can see.
